# Quiz e Relatório - Ensino Religioso (A Reforma e Seus Ecos)

Este repositório contém uma aplicação web interativa desenvolvida para a disciplina de Ensino Religioso (9º Ano).

## 🚀 Como Executar

Para rodar o projeto localmente ou hospedá-lo (por exemplo, via GitHub Pages):

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno.

## 📁 Estrutura de Arquivos

* `index.html` - Estrutura principal da aplicação HTML.
* `style.css` - Estilos e temas visuais da aplicação.
* `script.js` - Lógica interativa do quiz, pontuações, gráficos e efeitos de áudio.
